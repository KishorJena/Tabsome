# Tabsome APIs Documentation

This directory contains client-ready API reference documentation for consuming Tabsome backend services in external clients (e.g., GitHub Pages, web dashboards, companion apps).

## Modules

- **User Speed Dials (Collections)**: [`docs/apis/users/me/speed-dials`](./users/me/speed-dials/README.md)
  - Endpoints to list, fetch, create, update, upsert, and delete speed dial collections and manage bookmarks/folders for authenticated users.
