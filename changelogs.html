v2.5.6 Latest December 28, 2025

✨ Speed Dial Suggestions & Marketplace Enhancements

Significant improvements to speed dials, widget sharing, and marketplace UX.

  • ⚡ Speed Dial Suggestions – shows pre-created speed dials from our collection
  • 🔗 One-click Widget Sharing – publish widgets from local preview to the marketplace, no auth required
  • ⭐ Featured Widgets Control – enable or disable featured widgets from settings
  • 🌄 Expanded Wallpaper Collection – new wallpapers auto-appear in settings
  • 🧩 Set Widget – set widget by id or raw JSON
  • 🔐 Privacy Improvement – removed Top Sites feature to avoid Chrome's history-related permission
  • 🛍️ Marketplace Enhancements – improved layout, discovery, and overall UX
  • 🎨 Branding Tweaks – refined logo and updated website to tabsome.github.io
  • ? shortcut for quick access to shortcut/tips
  • 💬Native feedback form
  • Removed options to remove or export active widget from options page as we have better action button near widget
